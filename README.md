# 🛍️ MyShop — интернет-магазин на Django

Это учебный проект интернет-магазина, создаваемый в рамках курса по Django.  
Проект разрабатывается по GitFlow и будет дорабатываться на каждом уроке.

---

## 📦 Структура проекта

- `myshop/` — корневой проект Django
- `catalog/` — приложение каталога с домашней страницей и страницей контактов
- `templates/catalog/` — HTML-шаблоны с использованием Bootstrap

---

## 🚀 Технологии

- Python 3.10+
- Django 4.x
- Bootstrap 5 (через CDN)
- Git + GitFlow
