# 🛍️ MyShop — интернет-магазин на Django

Это учебный проект интернет-магазина, создаваемый в рамках курса по Django. 
Проект разрабатывается по GitFlow и будет дорабатываться на каждом уроке.

## Технологии:
- Python 3.10+
- Django 4.x
- Git + GitFlow

## Структура веток:
- `main` — стабильная версия проекта
- `develop` — основная ветка разработки
- `feature/*` — отдельные ветки под задачи и домашки
